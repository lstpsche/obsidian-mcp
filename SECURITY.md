# Security

Please report suspected security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/lstpsche/obsidian-mcp/security/advisories/new).
Avoid posting vulnerability details or proof-of-concept exploits in public issues.

Include the affected version, relevant configuration, reproduction steps, and the
potential impact. A minimal proof of concept and suggested fix are welcome. Remove
API keys, private vault content, and other sensitive data from attachments.

We will use the private report to investigate and coordinate any fix and disclosure.
